# AI Decisions

**작업마다 모델과 reasoning effort를 선택하는 Codex 실행 라우터.**

사용자 요청과 하위 작업을 OpenAI Decisions API로 분류하고, 명시적인 정책으로 실행 설정을 선택하는 프로젝트입니다.
